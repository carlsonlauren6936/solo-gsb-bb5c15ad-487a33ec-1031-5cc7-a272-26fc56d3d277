# 骑马钉小册子 PDF 拼版（Booklet Imposer）

供小型印刷店使用的小册子 PDF 拼版 Web 应用。上传 PDF 后，系统按**每张纸容纳 4 页**的骑马钉规则自动重排页码，提供每张纸正反页序预览，并可下载拼版后的 PDF。支持整本拼版与**分册签帖**两种模式。

技术栈：Node.js + Express + 原生 HTML/CSS/JavaScript + [pdf-lib](https://pdf-lib.js.org/)。

## 拼版规则

- 每张纸正反两面共放置 4 个页面（每面左右各一页）。
- 页数不是 4 的倍数时，在**文档末尾补空白页**后再拼版。
- 页码排列（从外向内，逐层递进）：
  - 第 1 张纸 **正面**：`末页 | 首页`
  - 第 1 张纸 **背面**：`第 2 页 | 倒数第 2 页`
  - 第 2 张纸 **正面**：`倒数第 3 页 | 第 3 页`
  - 第 2 张纸 **背面**：`第 4 页 | 倒数第 4 页`
  - ……依次向内递进。
- 输出纸张为横向，尺寸 = `2 × 面板宽` × `面板高`（如 A4 竖版小册子 → A3 横向）；每个原始页按**原页面尺寸 1:1**放置，不缩放。
- **混合尺寸适配**：各页尺寸或旋转方向（/Rotate）不一致时，按每页**旋转后的有效宽高**取全部页面宽高的最大值作为**统一面板尺寸**；每页按其显示方向 1:1 居中放入对应半区，空余区域透明留白。拼版摘要中会显示统一面板尺寸与页面方向（竖版 / 横版 / 方形）。

> 说明：页面尺寸不一致或带旋转的 PDF 会按上述规则自动适配，无需预先统一页面尺寸；页序与末尾补白规则不受影响。

### 分册签帖模式

骑马钉装订帖不宜过厚，可勾选「启用分册签帖」并设置**每帖最多纸张数（1～20 的整数）**：

- 每帖容量 = `4 × 每帖最多纸张数` 页，系统按**原始页序**把文档切成容量上限内的连续签帖。
- 各帖**独立按骑马钉规则排版**，**仅在每帖末尾补白**（每帖补白 0～3 页）；补白总数可能多于整册拼版。
- **最后一帖不足上限时按实际所需纸张数收尾**（纸张数 = `ceil(该帖页数 / 4)`），不强行凑满。
- 输出 PDF 仍为**一个文件**，纸张按**签帖顺序连续输出**（帖 1 的纸张 → 帖 2 的纸张 → …）。
- 摘要会列出帖数与每帖明细（**帖号 / 原始页范围 / 补白数 / 帖内纸张编号**），预览按帖分组展示；下载始终为一个文件。
- 未启用（不勾选，或不提交该参数）时保持原有**整册**行为。

举例：10 页文档、每帖最多 1 张纸（容量 4 页）→ 切成 3 帖：第 1 帖第 1～4 页（1 张、0 补白）、第 2 帖第 5～8 页（1 张、0 补白）、第 3 帖第 9～10 页（1 张、末尾补 2 白），共 3 张纸 6 个输出面。

## 一条命令启动（Docker Compose）

需安装 Docker（含 Compose 插件）。在项目根目录执行：

```bash
docker compose up -d --build
```

镜像构建时自动完成 `npm install`，容器启动即服务就绪，无需手动安装依赖。

启动后访问：

```
http://localhost:3000
```

停止：

```bash
docker compose down
```

## 本地运行（不使用 Docker）

要求 Node.js >= 18。

```bash
npm install
npm start
```

然后访问 http://localhost:3000 。

## 配置

通过环境变量配置（在 `docker-compose.yml` 的 `environment` 中修改）：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | 服务监听端口（容器内端口） |
| `MAX_FILE_SIZE_MB` | `50` | 单个上传 PDF 的大小上限（MB） |

如需更换宿主机映射端口，修改 `docker-compose.yml` 中 `ports` 的左侧端口，例如 `"8080:3000"`，然后访问 http://localhost:8080 。

> 分册签帖的「每帖最多纸张数（1～20）」是每次拼版时在页面（或接口字段 `sheetsPerSignature`）按需指定的参数，没有服务端环境变量；不提交即为整册模式。

## 使用方式

1. 浏览器打开应用，点击或拖入要拼版的 PDF。
2. （可选）勾选「启用分册签帖」，填写每帖最多纸张数（1～20，默认 4）；不勾选即按整册拼版。
3. 点击「开始拼版」。
4. 查看拼版摘要（装订模式 / 签帖数量与各帖明细 / 原始页数 / 补白页数 / 用纸张数 / 统一面板尺寸 / 页面方向）与每张纸正反面的页码预览（分册时按帖分组）；斜纹块表示补的空白页。
5. 点击「下载拼版 PDF」保存，文件名自动在原文件名后加 `-拼版` 后缀；分册结果同样为单个 PDF。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/impose` | multipart 表单字段 `pdf` 上传 PDF；可选字段 `sheetsPerSignature` 为每帖最多纸张数（1～20 整数），缺省或留空表示整册模式。返回拼版 PDF，页序方案在响应头 `X-Imposition-Plan`（URL 编码的 JSON，含 `panel` 统一面板尺寸与方向；分册时含 `mode:"signature"`、`sheetsPerSignature`、`signatures[]` 各帖明细） |
| `GET` | `/api/health` | 健康检查，返回 `{ "ok": true }` |

`X-Imposition-Plan` 关键字段：

- 通用：`mode`（`whole` / `signature`）、`sourceCount`、`paddedCount`（补白合计）、`sheets`（按输出顺序展平的全部纸张，分册时每张带 `signature` 帖号）、`sheetCount`、`panel`。
- 分册模式额外：`sheetsPerSignature`、`signatureCount`、`signatures[]`，每个签帖含 `signature`（帖号）、`sourceStart` / `sourceEnd`（原始页范围）、`sourceCount`、`paddedCount`（本帖末尾补白数）、`sheetCount`、`sheets[]`（帖内纸张编号 `sheet` 从 1 重新计数）。
- 非法 `sheetsPerSignature`（非整数、超出 1～20 等）返回 `400` 与 `{ "error": "..." }`；字段缺省/留空不影响旧调用方。
